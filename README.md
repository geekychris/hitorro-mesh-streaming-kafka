# Hitorro Mesh Streaming Kafka

Kafka LocalTable adapter for Hitorro Mesh agents — consumes a Kafka topic as a streaming partition of JVS messages with event-time watermarks, so the mesh can run SQL-over-streams queries against live Kafka topics.
